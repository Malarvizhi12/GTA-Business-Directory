# GTA Business Directory Dashboard

An interactive web-based data-analysis project that scrapes the public [GTASearch.com](https://www.gtasearch.com/) business directory, cleans and analyses the data with Pandas, and displays results in a professional Streamlit dashboard.

---

## Project Structure

```
gta_business_directory/
├── scraper.py          ← Collects data from GTASearch.com
├── dashboard.py        ← Streamlit interactive dashboard
├── data/
│   └── businesses.csv  ← Generated by the scraper
├── requirements.txt
└── README.md
```

---

## Robots.txt Compliance

Before any scraping, `robots.txt` was inspected at `https://www.gtasearch.com/robots.txt`:

```
User-Agent: *
Allow: /
Disallow: /api/
Disallow: /coming-soon
Disallow: /dashboard/
Disallow: /directory/search   ← disallowed
Disallow: /near-me
```

**The scraper uses `/directory/{category}/{city}?page={n}` URLs**, which are fully permitted.  
The disallowed `/directory/search` endpoint is **never called**.

## Quick Start (Windows)

### 1. Open a terminal in the project folder

```powershell
cd C:\Users\Malar\Desktop\gta_business_directory
```

### 2. Create and activate a virtual environment (recommended)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
pip install -r requirements.txt
```

### 4. Run the scraper

```powershell
python scraper.py
```

This collects up to **3 listing pages per category × city** combination (~3,300 listings in a few minutes).  
Data is saved to `data/businesses.csv`.

#### Optional flags

| Flag | Description |
|------|-------------|
| `--pages N` | Pages per category+city (default: 3) |
| `--enrich` | Also visit each detail page for website & description *(slow)* |

```powershell
# Collect more data
python scraper.py --pages 5

# Full detail enrichment (much slower — 1.5 s delay per detail page)
python scraper.py --enrich
```

### 5. Launch the dashboard

```powershell
streamlit run dashboard.py
```

The browser opens automatically at **http://localhost:8501**.

## What the Scraper Collects

| Field | Source |
|-------|--------|
| Business Name | Listing card `span.text-sm.font-semibold.text-ink` |
| Category | Listing card `p.text-xs.text-ink-muted` |
| Subcategory | Same element — after `·` separator |
| Address | Listing card `p.text-xs.text-ink-faint` |
| City | Derived from the URL city slug |
| Phone | `a[href^="tel:"]` on listing card or detail page |
| Website | `a[rel*="nofollow"]` inside detail page `<dl>` |
| Description | Detail page `section[aria-labelledby="business-description-heading"] p` |
| Rating / Reviews | **Not available** — the site's review system requires sign-in; no structured markup is present in the public HTML |
| Source URL | `/biz/{slug}` link on each card |

## Dashboard Features

- **KPI cards** – Total businesses, cities, categories, % with phone
- **Businesses by City** – Horizontal bar chart
- **Businesses by Category** – Donut pie chart
- **Top Categories** – Vertical bar chart
- **City × Category Heatmap** – Distribution matrix
- **Treemap** – Category → City drill-down
- **Filters** – Multi-select city, multi-select category, name search, has-phone toggle, has-website toggle
- **Interactive table** – Clickable website/source URLs
- **CSV download** – Export filtered results instantly

## Data Cleaning (Pandas)

The dashboard applies these transformations at load time:

1. Strip whitespace from all string columns
2. Replace empty strings with `NaN`
3. Standardise city names (e.g. `richmond-hill` → `Richmond Hill`)
4. Standardise category names (e.g. `restaurants` → `Restaurants & Food`)
5. Deduplicate by `(business_name, city)`
6. Convert `rating` and `num_reviews` to numeric (float/int)

## Updating the Selectors

If GTASearch.com changes its HTML structure, update the relevant constants in `scraper.py`:

```python
# Listing card selectors — in parse_cards()
name_el  = article.select_one("span.min-w-0.flex-1.truncate.text-sm.font-semibold.text-ink")
cat_el   = card_body.select_one("p.text-xs.text-ink-muted")
addr_el  = card_body.select_one("p.text-xs.text-ink-faint")

# Detail page selectors — in enrich_from_detail()
tel_el   = soup.select_one("dl a[href^='tel:']")
web_el   = soup.select_one("dl a[rel*='nofollow']")
desc_el  = soup.select_one("section[aria-labelledby='business-description-heading'] p")
```
